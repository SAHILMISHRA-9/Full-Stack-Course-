1. What is "conditional rendering"?
Ans. When we want to only sometimes on the page base on some kind of condition.

2. When would you use &&?
Ans. When you want to either display seomthing or NOT display something.

3. When would you use a ternary?
Ans. When you need to decide which of 2 things to display.

4. What if you need to decide between > 2 options on what is display?
Ans. if...else if...else conditional or maybe a `switch` statement or ternary with multiple condition.
